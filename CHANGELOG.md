## [0.1.0] - 2026-08-30
### Added
- Initial release
- Playwright browser auth integration for secure login
- Async parallel downloads (MP3, MP4, WAV)
- ID3 tagging and cover art embedding
- Auto-organized folder structures
- Resume interrupted downloads capability
- Filtering support (date ranges, liked only, minimum plays)
- Web dashboard for monitoring progress
